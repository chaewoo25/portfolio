# 🚀 개인 포트폴리오 웹사이트

순수 HTML, CSS, JavaScript로 구현한 개인 소개 및 프로젝트 포트폴리오 웹사이트입니다.

## 🔗 배포 링크
- **배포 주소**: https://chaewoo25.github.io/portfolio/

## 🛠️ 사용 기술 (Tech Stack)
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **API**: GitHub REST API
- **Icons & Fonts**: Font Awesome, Google Fonts (Noto Sans KR)
- **Deployment**: GitHub Pages

## ✨ 주요 기능
1. **시맨틱 마크업**: 웹 접근성을 고려한 HTML 구조 설계
2. **반응형 웹**: 모바일, 태블릿, 데스크톱 맞춤 레이아웃 적용
3. **다크 모드**: `localStorage`를 활용한 테마 저장 및 토글 기능
4. **GitHub API 연동**: 최근 저장소 목록을 동적으로 불러와 카드 형태로 출력
5. **Contact Form 유효성 검사**: JavaScript를 활용한 실시간 입력값 검증
